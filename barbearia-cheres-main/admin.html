Semana padrão

Os horários de cada dia da semana, válidos para todas as semanas. Toque em um dia para ligar, desligar ou adicionar horários.

Dias especiais

Uma data com horário diferente da semana padrão: véspera de feriado, folga, atender até mais tarde ou abrir numa segunda.

Várias datas de uma vez

Para fim de ano, férias ou feriado prolongado. Ex.: de 20/12 a 31/12, das 09:00 às 21:00.

Serviços e preços

Alterações não salvas
  • O que você salvar aparece na hora no site (lista de serviços e agendamento).
  • Preço novo vale para os próximos atendimentos. O que já foi atendido continua com o valor da época.
  • Para tirar um serviço do site, desmarque "No site". Assim, quem já agendou não é afetado.
  • O nome de um serviço salvo não muda (os agendamentos guardam o nome). Para trocar o nome, crie um serviço novo e desmarque "No site" no antigo.
  • Só serviços com "Corte" no nome contam para a fidelidade.
